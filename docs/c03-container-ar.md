# C-03 container AR and indoor walkthrough

Published through the existing Vite public-assets / GitHub Pages workflow at `c03/index.html`, registered as an interactive scene in the existing Model Library. The existing library and AR pages remain available.

The standalone page contains the current container mesh, full-size Android Scene Viewer launch, iPhone/iPad Quick Look launch, browser WebXR ground-placement mode and an eye-level indoor walkthrough. English/Japanese/Both selectors retain permanent bilingual labels. No client contact details are included.

The nominal envelope is 12.530 x 2.438 x 2.910 metres. GLB and USDZ files use metres at 1:1 scale. Android native launch requests AR-only mode and disables resizing; iOS launch disables content scaling. Browser AR uses a fixed unit scale, surface hit testing and tap-to-place. This is separate from the existing Lighthouse camera-relative method, which remains unchanged.

Walkthrough movement, zone jumps, language controls, save/reopen and exports were checked in desktop/mobile browser emulation. Binary structure, metre units, USDZ alignment and colour materials were checked. Actual camera tracking and Apple Quick Look rendering have not been exercised on a physical phone. CAD construction allowances, readiness of the business fit-out, and permits remain separate matters.

The user requested this model-library addition independently of the pending supplier API capability; its credential blocker and roadmap are retained.
